# 🌿 SensIQ — AI Powered Adaptive Navigation System

### Urban Sensory Intelligence for Inclusive Smart Cities

SensIQ is an AI-powered adaptive navigation platform designed to help individuals navigate cities safely by minimizing sensory overload caused by noise, lighting, and crowd intensity.

Unlike traditional navigation apps that prioritize the fastest route, SensIQ prioritizes **emotional comfort, safety, and accessibility**.

---

## 📌 Problem Statement

Modern cities focus on **physical accessibility** (ramps, elevators) but often ignore **sensory accessibility**.

Millions of people experience distress due to:

- Excessive traffic noise
- Overcrowded public spaces
- Harsh or flickering lighting
- Sudden environmental triggers

### Affected Groups

- Neurodivergent individuals
- Anxiety disorder patients
- Migraine sufferers
- Elderly citizens
- Sensory-sensitive children

### Consequences

- Anxiety and panic episodes
- Avoidance of public environments
- Reduced independence
- Emotional stress

SensIQ bridges this invisible accessibility gap.

---

## 🚀 Solution Overview

SensIQ is an AI-driven smart navigation system that:

- Measures real-time sensory stress
- Predicts overload risk
- Personalizes routes using user sensitivity profiles
- Suggests calm alternative routes
- Recommends optimal time windows to travel

### Transformation

**Fastest Route → Safest Experience**

## ⭐ Key Features

### 👤 User Personal Sensory Profile

Users configure:

- Noise Sensitivity
- Light Sensitivity
- Crowd Tolerance

The system adapts route recommendations accordingly.

---

### 🏷 Community Tagging Interface

Users contribute sensory data:

- Noise levels
- Lighting intensity
- Crowd density

This builds a **crowd-powered city intelligence network**.

---

### 🧠 AI Sensory Load Index (SLI)

Core AI engine performs:

1. Compute SLI Score
2. Predict overload risk
3. Classify sensory zones
4. Optimize routes

---

### 🗺 Smart Routing Engine
